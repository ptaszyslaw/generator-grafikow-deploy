# generator-grafikow-deploy

Gotowe pliki https://grafik.ptaszynski.pl/ (Generator grafików, PWA). Nie edytuj ich tutaj — źródła i skrypt wdrożenia są w prywatnym repozytorium `generator-grafikow`.

Pliki zawierają tylko program i zmyślone dane przykładowe; grafiki użytkowników nigdy tu nie trafiają.

cPanel → Git Version Control → generator-grafikow-deploy → „Update from Remote”, potem „Deploy HEAD Commit”.
